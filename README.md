# 历史知识库 · 高中三年历史知识清单

一个**完全离线可用**的历史学习工具：左侧章节树、中间知识点列表、右侧详情，另有点击即开的**独立解析页**与**全球纪年时间线**。支持全文检索、笔记、自定义知识点、错题本（1/3/7/15/30 天排期）、知识点复习打卡与月历、多种备份。

登录是可选的：不登录时全部功能照常在本机运行；登录后通过 Supabase 把 `hs.user.v1` 这一份用户数据同步到云端，换设备打开同一邮箱即可取回笔记、复习、错题和自定义知识点。

- 纯静态；主体功能无任何联网依赖，断网可继续使用；只有主动登录 / 云同步时才会访问 Supabase。
- 未登录时用户数据只存浏览器 localStorage，与 `data/` 静态数据严格分离，重新部署不会覆盖。
- 当前内容：**66 课共 323 条**，章节树完整录入 2 册 / 6 部 / 21 单元 / 66 课。314 条带原文摘录，9 条因扫描页无对应正文标为“考点归纳”，界面会显示不同徽标。
- 视觉：编辑感玻璃主题（山景 Hero、四格学习概览、暖纸阅读面、宋体标题），支持明暗主题切换，桌面 / 平板 / 手机三档响应式；时间线与主站共用同一套设计语言。
- 线上地址：<https://sereniiiii.github.io/history/>（时间线：`/timeline.html`；单条解析：`/detail.html?id=<知识点ID>`）。

## 本地启动

```bash
cd history
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

> 不能直接双击 `index.html`（`file://` 下 fetch JSON 与 Service Worker 会被浏览器拦截）。

## 功能与快捷键

| 操作 | 方式 |
| --- | --- |
| 全局搜索 | `/` 或 `Cmd/Ctrl + K` |
| 关闭弹层 / 清空搜索 | `Esc` |
| 上下切换知识点 | `j` / `k` |
| 快捷键面板 | `?` |

- **检索**：一个框同时搜知识点、笔记、错题；关键词高亮；空结果给最相近 5 条；支持按书 / 章 / type / 难度 / 掌握状态筛选。
- **知识点**：树形展开；可标「已掌握 / 待复习」；详情含要点、原文摘录（有则显示）、关键词、可能考法。
- **自定义知识点**：表单创建，来源固定显示「我创建」，可编辑、删除。
- **错题本**：题干 / 我的答案 / 正确答案 / 错因（概念不清·审题失误·计算错·记忆偏差）/ 关联知识点 / 错误次数 / 上次与下次复习；按 1、3、7、15、30 天排期，到期在首页提示。
- **复习打卡**：每张知识点卡片底部有「今日已复习」勾选框；点进知识点可在右侧或解析页看到复习月历，已复习日期用深色标出，并显示本月 / 累计天数。

## 单条解析页

知识点卡片的「解析 ↗」、详情栏的「完整解析 ↗」都会打开 `detail.html?id=<知识点ID>`（新标签页），适合投屏、打印或单独复习一条。

- **原文依据**：有摘录时逐字展示并标来源；没有原文的「考点归纳」会明确说明，不虚构。
- **展开解析**：关键词高亮，并说明它在册 / 部 / 单元 / 课次里的位置。
- **可能怎么考**：优先用条目自带的 `commonq`，否则按 `type` 给出选择题 / 材料题的答题角度。
- **注意点**：从原文抽取“最早 / 标志 / 开始 / 完成 / 根本 / 直接”等程度词，另附通用核对清单。
- **同课知识网络**：把同一课的其他条目列成可继续点击的卡片。
- **时间线坐标**：同一条目的纪年事件与同课事件；可跳到时间线或回知识库定位。解析页不再显示教材页码，只保留考点内容。
- **我的笔记**：解析页底部可直接写、改、清空这条考点的个人笔记；自动保存到本机，与主站右侧「我的笔记」共用同一份数据，导出备份时一并带走。
- **复习月历**：解析页底部「07 复习月历」可直接勾选今日复习、翻看上 / 下月；深色日期为已复习，今日用描边标出。
- 复制链接、明暗主题、复习月历、移动端单列均可用。

## 历史时间线

顶栏「时间线」进入独立页面：内置 104 个有明确纪年的考点，中国史与世界史放在同一条年份轴上。

- **全球总览 / 分时代**两种视图：总览从“前 2070”一路排到“2020”，分时代仍按六个时代分段。
- **地区**：添加事件时可选中中国、世界、亚洲、欧洲、非洲、北美洲、南美洲、大洋洲、中东、其他，或选「自定义（手打）」输入东南亚、巴尔干、拉丁美洲等任意地区；**地区筛选**会按已用地区动态出现，另有「自定义」汇总；**阶段筛选**：全部 / 中国古代 / 中国近代 / 中国现代 / 世界古代 / 世界近代 / 世界现代。
- **颜色**：时间轴圆点按地区着色（中国绛红、世界靛青、其他橄榄），卡片左边框与阶段标签按历史阶段着色；顶部提供图例。
- **添加事件**：顶栏「＋ 添加事件」填写时间（支持“前2070”“1919年5月4日”“约1929”等）、标题、说明、标注、地区、阶段；保存后立即按年份插入时间线，可编辑 / 删除。
- **标注**：自定义事件可写“易错点 / 对比对象 / 对应课次”，在卡片内以浅色注释块显示。
- 点内置事件 → `detail.html?id=<知识点ID>`；自定义事件不关联知识点，只在本机浏览器保存。
- 时间线内搜索（`/` 聚焦）；导出 `CSV` / `JSON` 会包含自定义事件；约数标 `~`。
- 与主应用共用 `sw.js` 离线缓存；断网后仍可打开时间线。

localStorage 键：`hs.timeline.custom.v1`（只存自定义事件，不写入 `data/timeline.json`）。


## 账号登录与跨设备同步（可选）

站点不登录也能完整使用；登录入口只在主站顶栏，普通邮箱 Magic Link，不设密码。

### 一次性配置 Supabase

1. 打开 Supabase Dashboard → 项目 `history-kb` → **SQL Editor**。
2. 把仓库里的 `supabase-setup.sql` 整段粘贴进去，点 **Run**。它会创建 `public.history_user_state`、开启 RLS，并只允许登录用户读写自己那一行。
3. 打开 **Authentication → URL Configuration**，把下面两个地址都加入 **Redirect URLs**，并保存：
   - `https://sereniiiii.github.io/history/`
   - `http://127.0.0.1:8787/`
4. 确认 **Authentication → Providers → Email** 已开启（当前项目已开）。
5. 前端配置在 `assets/js/supabase-config.js`，只放 Project URL 和 Publishable key；**绝不能**把 Secret key / service_role 放进来。

### 使用

1. 顶栏点「登录」，输入邮箱，点「发送登录链接」。
2. 到邮箱点开链接，会回到站点并显示「已同步」。
3. 之后每次本地保存后约 1.5 秒自动上传；换设备用同一邮箱登录即取回。
4. 登录后首次同步按 `updatedAt / updated_at` 比较，较新的整份覆盖较旧的；云端覆盖本机前会自动留一份本机快照「登录同步前」。
5. 点顶栏「已同步」可退出登录；退出后本机数据仍在，继续离线使用。

> 云端存的是整份 `hs.user.v1` JSON，不做逐条合并。多设备同时编辑同一条时，后保存的版本会覆盖较早的版本；重要改动请先用「备份」导出完整 JSON。

## 数据备份

右上角「备份」：

1. **导出完整 JSON**：笔记 + 自定义知识点 + 错题 + 复习记录 + 配置，文件名带日期时间。
2. **导入 JSON**：先校验 schema，冲突时可选「覆盖」或「合并」；合并按 id 去重、保留较新修改。
3. **自动快照**：导入、批量标记、批量删除前自动写入，保留最近 5 份，可一键回滚。
4. **额外导出**：错题 CSV（Excel 可直接打开）、知识点 Markdown（Obsidian 可直接收）。复习记录随完整 JSON 备份。
5. 首页显示「上次备份时间」，超过 7 天显示一行提醒。

localStorage 键：

- `hs.user.v1` 用户数据（含 `reviews: { [知识点ID]: [YYYY-MM-DD, ...] }`）
- `hs.snapshots.v1` 快照（最多 5 份）

## 加新书 / 补全其余课时

当前已覆盖 66 课 / 323 条；若后续补新书或改结构，按下面的流程逐条人工核对原文，禁止让模型自由发挥：

1. **OCR**：扫描页用 `_tools/ocr`（macOS Vision）逐页识别，输出 `_work/ocr_raw.json`；清洗成 `_work/page_text.json`（去页脚、按几何合并折行）。OCR 只作辅助，表格列错位、形近字必须回图核对。
2. **抽知识点**：按课逐页读图，产出 `data/knowledge.json`，字段固定：
   `id / book / unit / lesson / title / content / excerpt / source / page / pdfPage / keywords / type / difficulty / commonq`。界面不再展示页码，只把页码留在数据层备查。
   硬规则：`title ≤ 20` 字、`content ≤ 120` 字、`excerpt ≤ 100` 字且**一字不改**、`keywords 3–6` 个、四要素（摘录+书名+章+节+页码）齐全；找不到页码写「未定位」，不许编。
3. **校验**：跑 `_work/build_knowledge.py`（长度、字段、类型硬校验），再把摘录与 `page_text.json` 做字符序列比对，未命中的逐条回图确认。
4. **章节树**：新课若改变结构，改 `data/books.json`（书→部→单元→课），并同步 `knowledge.json` 的 `unit/lesson`。
5. **索引**：重建 `data/aliases.json`（新术语别名）与 `data/pinyin.json`（新字注音），刷新页面即自动重建倒排索引。
6. **离线缓存**：改 `sw.js` 里的 `CACHE = 'hs-static-v14'` 版本号，让老用户换到新资源。

## 已知限制

- 内容已覆盖 66 课 / 323 条；9 条扫描页无正文的条目只保留“考点归纳”，没有原文摘录。
- OCR 对表格与形近字有误差，所有摘录均已回图人工核对；后续扩量必须沿用同一流程。
- 自定义时间线事件只存在当前浏览器 localStorage，不随账号同步；换设备请用时间线页的 JSON 导出备份。
- 云同步按整份 JSON 的较新时间戳覆盖，不做逐条合并；多设备同时改同一条时以最后保存者为准。
- 旧浏览器若不支持 `color-mix()` / `backdrop-filter`，玻璃与混色会降级为实色，不影响阅读与操作。
